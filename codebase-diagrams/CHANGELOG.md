# Changelog

All notable changes to `codebase-diagrams` are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the plugin uses
[Semantic Versioning](https://semver.org/) for the `version` in `plugin.json`.

## [1.0.0]

- Initial release as an Agent Plugin: the `codebase-diagrams` skill from
  [markbsigler/skills](https://github.com/markbsigler/skills). The render script
  is now a portable Python script (`render_diagrams.py`) instead of bash.
